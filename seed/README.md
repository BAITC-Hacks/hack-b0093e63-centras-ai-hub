# seed/ — снимок данных ekt.kz для локального запуска

Этот каталог — статичный снимок каталога ekt.kz, зафиксированный **2026-09-23**. Он позволяет
поднять AI-консультанта локально (или в CI/у жюри хакатона) без обращения к ekt.kz и без ключей
команды — только со своим `OPENAI_API_KEY`. Используется скриптом `npm run setup:local`
(`ingest --dir seed`).

## Состав

| Файл | Содержимое | Кол-во |
| --- | --- | --- |
| `products.jsonl` | Товары категории «Лампы» (`/catalog/svetilniki_lampy/lampy/`) | 89 |
| `categories.jsonl` | Категории каталога (путь до корня для каждой из них) | 24 |
| `pages.jsonl` | Информационные страницы (доставка, оплата, FAQ, бренды и т.п.) | 123 |
| `branches.json` | Филиалы/магазины ekt.kz | 9 |
| `scrape-report.json` | Отчёт скрапера о прогоне, породившем этот снимок | — |

Источник: [ekt.kz](https://ekt.kz/), категория `/catalog/svetilniki_lampy/lampy/` целиком
(в категории «Лампы» ровно 89 уникальных товаров — это не усечение, а полный размер категории
на дату снимка).

## Как обновить снимок

1. Соберите свежие данные скрапером в `data/` (по умолчанию бежит по всему каталогу; для
   быстрого прогона по одной категории задайте `SCRAPER_CATEGORY` и `SCRAPER_MAX_PRODUCTS`,
   см. `.env.example`):

   ```sh
   SCRAPER_CATEGORY=/catalog/svetilniki_lampy/lampy/ SCRAPER_MAX_PRODUCTS=100 npm run scrape
   ```

2. Скопируйте результат в `seed/`:

   ```sh
   npm run seed:update
   ```

   (эквивалент `cp data/{products.jsonl,categories.jsonl,pages.jsonl,branches.json,scrape-report.json} seed/`)

3. Обновите таблицу выше (даты и количества) и закоммитьте `seed/*`.

Снимок не перегенерируется автоматически — это осознанный шаг: `seed/` должен всегда быть
воспроизводимым и не зависеть от доступности ekt.kz.
