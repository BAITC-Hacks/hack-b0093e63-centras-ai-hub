# EKT AI-консультант — расширение Chrome

Подключает ИИ-консультанта к настоящему сайту [ekt.kz](https://ekt.kz/) без изменений на стороне сайта.
Консультант отвечает в чате и действует на странице: открывает карточки товаров, подсвечивает цену
и кнопку «Купить», по просьбе покупателя нажимает «Купить», открывает и заполняет формы
«Оставить заявку» и «Купить в 1 клик», вводит запрос в поиск. Формы отправляет только сам покупатель.

## Установка (2 минуты)

1. Скачайте папку `extension/` из репозитория (или весь репозиторий).
2. Откройте `chrome://extensions` (Edge: `edge://extensions`, Яндекс Браузер: `browser://extensions`).
3. Включите «Режим разработчика» (переключатель справа вверху).
4. Нажмите «Загрузить распакованное» и выберите папку `extension/`.
5. Откройте <https://ekt.kz/catalog/svetilniki_lampy/lampy/> — справа внизу появится кнопка «Задать вопрос».

Попробуйте: «Подбери лампу E27 4000K» → «Открой карточку» → «Добавь в корзину»;
«Хочу оформить возврат»; «Где вы находитесь в Астане?».

## Как устроено

| Файл | Что делает |
|---|---|
| `manifest.json` | Manifest V3: content script только для `https://ekt.kz/*` и `https://www.ekt.kz/*`, никаких разрешений сверх этого |
| `content.js` | Вставляет `<script src="…/widget.js" data-api="…" data-city="…">` в страницу. Скрипт работает в мире страницы, поэтому может открывать модальные окна сайта (Bootstrap/jQuery ekt.kz) |
| `widget.js` | Сборка виджета из `web/src` (`npm run build:web` обновляет копию здесь) |
| `icons/` | Иконки 16/48/128 px |

- Диалог хранится в `localStorage` ekt.kz и восстанавливается после каждого перехода по сайту;
  действия, пришедшие вместе с переходом (подсветить цену, заполнить форму), выполняются на новой странице.
- Адрес API зашит в `content.js` (`https://gqdwplbvxopanapxzlaw.supabase.co/functions/v1/chat`).
  Для локального бэкенда замените его и перезагрузите расширение.
- Если сайт уже подключил консультанта сам (продакшен-сниппет), расширение ничего не делает.

## Продакшен без расширения

Тот же тег в шаблоне Bitrix (`footer.php`) перед `</body>`:

```html
<script src="https://<хостинг виджета>/widget.js"
        data-api="https://gqdwplbvxopanapxzlaw.supabase.co/functions/v1/chat" defer></script>
```

У ekt.kz нет Content-Security-Policy, CORS функции чата разрешает `https://ekt.kz`.
